# Setup Language (设置沟通语言)

该技能用于配置整个项目的"全局语言与沟通规范"。它会更新根目录下的 `CLAUDE.md` 以及相关文档，确保所有子代理在后续协作中严格遵守该规范。

## 工作流 (Workflow)

### 1. 确认首选语言 (Select Language)

首先询问用户希望使用哪种语言进行沟通：
- **中文 (Chinese)**: (推荐) 强制所有代理及文档使用中文。
- **English**: 所有交流及文档将使用英文。
- **其他 (Other)**: 用户指定的其他语言。

### 2. 更新配置文件 (Update Configuration)

根据用户的选择，将"全局语言与沟通规范"写入以下文件：

#### 根目录 `CLAUDE.md`
在文件顶部（紧随标题之后）插入以下内容：

```markdown
---

## 全局语言与沟通规范 (Language & Communication Mandate)

> **最高优先级指令**：本章节定义的语言规范具有最高法律效力，覆盖所有代理（Agents）及其子任务。

- **强制语言**：所有代理与用户之间的沟通、方案建议、任务报告及交互界面必须**全量使用 [所选语言]**。
- **情景识别与术语**：必须精准识别"游戏工作室"开发场景，使用地道、专业的 [所选语言] 行业术语。
- **自然口语表达**：回复应自然、口语化，模拟工作室资深同事间的真实协作情景。识别并适配特定语境，严禁生硬的"翻译腔"。
- **二次核对机制**：在输出任何内容前，代理必须进行内部审查，确保表达习惯符合 [所选语言] 母语使用者的直觉，逻辑严密且无语病。

---
```

#### `.claude/CLAUDE.md`
同样在文件显著位置插入上述规范，以确保框架核心层级的约束力。

### 3. 验证与应用 (Validation & Application)

1. **展示草案**：在执行写入操作前，向用户展示即将写入 `CLAUDE.md` 的内容摘要。
2. **获得批准**：询问"我可以将这些语言规范写入您的配置文件吗？"
3. **即时生效**：写入完成后，立即切换到该语言进行后续对话。

## 协作协议 (Collaborative Protocol)

本技能严格遵循"提问 -> 方案 -> 决策 -> 草案 -> 批准"的原则：
- 在修改任何文件前，必须获得用户明确授权。
- 提供清晰的撤销或修改选项，如果用户对术语偏好有特殊要求。

## 术语建议 (Terminology Guidance)

如果用户选择中文，建议代理在执行任务时自动适配以下术语：
- **Vertical Slice**: 垂直切片
- **Game Design Document (GDD)**: 游戏设计文档
- **Core Loop**: 核心循环
- **Sprint**: 冲刺
- **Milestone**: 里程碑
- **Build**: 构建/版本
