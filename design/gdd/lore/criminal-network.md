## 1. 网络概述

### 1.1 基本描述

毒雾湾的人口贩卖网络——在地下世界中被称为"寂静贸易"——是整个毒雾湾非法经济中最庞大、最复杂、也是最黑暗的组成部分。

这个网络不是一个统一的组织，而是一套由多个派系共同维护的"基础设施"和"运作流程"。凋亡议会提供保护伞，锈网提供情报服务，灰烬团提供武装护卫，各地的"家族"和"中间人"负责具体的"货源"组织和"买家"对接。

**规模估计**:
- 年均"处理量": 约3000-5000人
- 直接从业人员: 估计500-1000人
- 间接相关人员: 估计3000-5000人
- 年均"产值": 约2-5亿毒雾湾元（无法准确统计）

### 1.2 网络的性质

这个网络的核心特征是**专业分工**与**互相依存**：

- 没有人拥有整个链条
- 每个环节都由专业的人负责
- 议会是"裁判"而非"运动员"
- 任何人试图单干都会被系统性地消灭

---

### 1.3 关键时间线背景

**锈网的起源（1987年/约39年前）**:
> 1987年，锈网的前身——一个地方性的监控设备收集网络——在锈港工业废墟区建立。创始人艾琳娜·科尔特斯最初只是想靠卖情报谋生。艾琳娜1972年生，1987年时15岁开始收集废弃设备，网络在1990年代初期正式建立。1994年，她儿子被拐事件（后被找到但已受创）成为她将网络做大做强的转折点。

## 2. 网络层级结构

### 2.1 三层架构

```
┌─────────────────────────────────────────────────────────────┐
│                    第一层: 保护层                            │
│         (凋亡议会 + 政府内部代理人)                          │
│                                                              │
│  ┌──────────────────────────────────────────────────────┐    │
│  │                   第二层: 服务层                       │    │
│  │      (锈网 + 灰烬团 + 金融网络 + 医疗网络)             │    │
│  │                                                       │    │
│  │  ┌────────────────────────────────────────────────┐    │    │
│  │  │               第三层: 执行层                     │    │    │
│  │  │    (货源组织者 + 中转站 + 押送队 + 终端销售)     │    │    │
│  │  └────────────────────────────────────────────────┘    │    │
│  │                                                       │    │
│  └──────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 层级详细说明

**第一层: 保护层 (Protection Layer)**

| 组成部分 | 职能 | 代表人物/实体 |
|---------|------|-------------|
| 凋亡议会 | 最高保护伞，纠纷仲裁，关系维护 | 议长马库斯·韦恩 |
| 政府渗透者 | 警局、法院、边境管理部门的"自己人" | 影子警局网络 |
| 法律顾问 | 用法律手段保护网络成员免于起诉 | 议会的"白手套"律师 |

**第二层: 服务层 (Service Layer)**

| 组成部分 | 职能 | 代表人物/实体 |
|---------|------|-------------|
| 锈网 | 情报收集，买家/卖家信用评估，通讯协调 | 织网者艾琳娜 |
| 灰烬团 | 高价值货物押送，重要路线护卫 | 各联队长 |
| 金融网络 | 洗钱，资金转移，跨境支付 | 独立于议会的银行家 |
| 医疗网络 | "验货"，健康检查，必要时"处理" | 若干无牌诊所 |

**第三层: 执行层 (Execution Layer)**

| 组成部分 | 职能 | 代表人物/实体 |
|---------|------|-------------|
| 货源组织者 | 在"源头"寻找、收集、筛选"货物" | 各区域的地头蛇 |
| 中转站 | 临时关押，分类，"整修"，存储 | 各城市的秘密设施 |
| 押送队 | 负责从一个点到另一个点的运输 | 灰烬团或私人承包商 |
| 终端销售 | 直接与买家交易，完成交付 | 网络的最外层 |

## 3. "货源 → 中转 → 买家"流程

### 3.1 货源阶段 (Sourcing)

**目标群体**:
根据历史数据和案例分析，最容易被盯上的目标群体包括：

| 群体 | 风险等级 | 典型来源 |
|------|---------|---------|
| 无家可归者 | 极高 | 街头、收容所 |
| 农村贫困人口 | 高 | 偏远村庄、盐花镇 |
| 城市边缘青年 | 高 | 贫民窟、问题家庭 |
| 孤儿/留守儿童 | 极高 | 孤儿院、破碎家庭 |
| 非法移民 | 极高 | 边境、地下窝点 |
| 失踪者的朋友/邻居 | 中 | 追踪调查时灭口用 |

**收集方式**:

1. **"糖果陷阱"**: 以工作机会、婚姻介绍、教育机会为诱饵，将目标骗至陌生地点
2. **"直接绑架"**: 深夜在街上直接抓人，适用于无依无靠的流浪者
3. **"购买"**: 从其他小犯罪团伙手中购买已经"收集"来的人口
4. **"自愿"**: 某些极端贫困的家庭主动"卖掉"家庭成员（事后反悔的情况并不罕见）

**"验货"程序**:
当"货物"被收集后，会有一轮"验货"：
- 身体健康检查（有病的不值钱）
- 年龄和外貌评估（决定最终用途）
- 性格评估（太有反抗性的需要"驯化"）
- 来源核查（太"烫手"的货源会被拒绝）

### 3.2 中转阶段 (Transit)

**中转站类型**:

| 类型 | 规模 | 停留时间 | 功能 |
|------|------|---------|------|
| 初级站 | 1-5人 | 1-7天 | 临时关押，等待"凑货" |
| 中级站 | 5-20人 | 1-4周 | 分类、记录、初步"驯化" |
| 高级站 | 20-50人 | 1-3月 | 等待运输，特殊"整修" |
| 边境站 | 不定 | 数小时-1天 | 跨境运输的中转点 |

**中转站位置**:
- 锈港下港区: 多个废弃仓库，防空洞
- 工业废墟区: 化工厂宿舍、废弃厂房
- 边境市场: 边境附近的农场、仓库
- 灰烬城周边: 偏远村庄的废弃建筑

**"货物"处理**:

在中转期间，"货物"会经历以下处理：

1. **文档伪造**: 制作假身份证件，包括假名、假年龄、假来源
2. **身体"整修"**: 清洗、换衣服、剪发，某些情况下甚至有整形手术
3. **心理"驯化"**: 通过威胁、殴打、药物或更极端的手段迫使受害者"顺从"
4. **标记**: 在隐秘部位做标记（如纹身、刻痕），便于识别，也是一种所有权的象征

### 3.3 买家阶段 (Buyer Delivery)

**买家类型**:

| 类型 | 需求 | 支付能力 | 典型买家 |
|------|------|---------|---------|
| 家庭买家 | 劳动力、性奴仆 | 中等 | 偏远地区的富裕家庭 |
| 组织买家 | 团体劳动力 | 高 | 境外黑工厂、矿场 |
| 色情行业 | 性剥削 | 中-高 | 妓院、老鸨 |
| 器官贩卖 | 器官摘取 | 极高 | 地下医疗网络 |
| 神秘买家 | 未知目的 | 未知 | 苍白之手? |
| 复仇买家 | 特定目标 | 不等 | 腐败官员的情敌等 |

**交付方式**:
- **直接交付**: 买家亲自到中转站"提货"
- **送货上门**: 网络派人将"货物"送到约定地点
- **边境交接**: 在边境市场或其他中转点完成跨境转移

**售后追踪**:
网络对已交付的"货物"有一定程度的追踪：
- 短期追踪：确保买家满意（不满意的买家会找麻烦）
- 防止"退货"：一旦交易完成，几乎不可能退货
- 二次销售：某些"货物"在第一次交付后会被"转手"或"回收"

### 5.1 价格体系

"货物"的价格因类型、质量、市场行情而差异巨大。以下是参考价格区间（毒雾湾元）：

| 类型 | 收购价 | 批发价 | 零售价 | 备注 |
|------|--------|--------|--------|------|
| 成年男性劳动力 | 500-2000 | 3000-8000 | 8000-15000 | 体力劳动用途 |
| 成年女性 | 1000-3000 | 5000-12000 | 15000-30000 | 性奴仆价格更高 |

| 儿童 | 3000-8000 | 10000-25000 | 30000-60000 | 最易出手 |
| "特殊货源" | 面议 | 面议 | 无上限 | 包括名人、官员家属等 |

### 5.2 利润分配

典型的利润分配比例（以一次零售交易为基准）：

```
总利润 (零售价 - 原始成本)
    │
    ├── 货源组织者: 15-20%
    │       └── "辛苦费" + 风险补偿
    │
    ├── 中转站运营: 10-15%
    │       └── 关押成本 + "驯化"成本 + 损耗
    │
    ├── 押送/护卫: 10-15%
    │       └── 灰烬团或私人护卫的费用
    │
    ├── 情报费: 5-10%
    │       └── 锈网的情报服务费
    │
    ├── 保护费: 15-20%
    │       └── 交给凋亡议会的"过路费"
    │
    └── 网络管理层: 25-35%
            └── 包括洗钱、法律服务、关系维护
```

### 5.3 洗钱渠道

网络产生的利润通过以下渠道洗白：

1. **合法商业**: 餐厅、酒店、按摩店、酒吧——特别是那些现金交易比例高的行业
2. **房地产**: 购买房产后出租或出售，是沉淀大额资金的好方式
3. **境外账户**: 通过边境市场的"贸易公司"进行跨境资金转移
4. **艺术品**: 购买低价艺术品后高价"拍卖"，资金转移

## 6. 与派系的关系

### 6.1 凋亡议会：保护伞

**关系描述**: 议会与网络的关系是"最高保护"——他们从网络中抽取"保护费"，同时确保网络能够正常运作。

**具体职能**:
- 警局不会调查相关案件
- 法院不会起诉相关人员
- 必要时提供"证人"消失的服务
- 调解网络内部的纠纷

**典型案例**:
> 2024年，一名锈港警员试图调查下港区的一个中转站。他提交了一份报告。两天后，他被调职到边境市场的一个偏远哨站。一周后，他在一次"交通事故"中死亡。

### 6.2 锈网：情报通道

**关系描述**: 锈网与网络是"商业合作"——锈网提供情报服务，网络支付费用。

**具体服务**:
- 买家的信用评估（能不能付钱）
- 货源地的安全评估（会不会被查）
- 运输路线的实时监控（有没有人跟踪）
- 潜在"货物"的背景调查（值不值得出手）

**典型案例**:
> 锈网曾向一个境外买家提供情报：某个毒雾湾偏远村庄有一批"优质货源"——23名14-16岁的少女。最终这笔交易的成交价为140万毒雾湾元。锈网从中抽取了约8万元的情报费。

### 6.3 灰烬团：武装护卫

**关系描述**: 灰烬团为网络提供"高价值货物"运输的武装护卫，是网络最重要的外部合作伙伴。

**【同步说明】**: 本节兵力数据与factions.md 4.3节保持一致。

**兵力规模**:
- **常备作战力量**: 200-320人（4支联队，每队50-80人）
- **预备役成员**: 超过500名（战时动员可扩充至2000+）
- **注**: 超过500名预备役与200-320常备力量属于不同维度——前者是战时动员的潜在兵源，后者是现役作战人员

**服务内容**:
- 陆路运输的全程护卫
- 中转站的安保
- 紧急情况下的武力支援
- 必要时"处理"逃跑的"货物"

**典型案例**:
> 灰烬团三联队负责从锈港到边境市场的运输路线。每次任务由15-20名武装人员护送三到五辆货车。每趟任务的护卫费用约为5-8万毒雾湾元。据信，这条路线的"货物"运输量占网络总运输量的40%以上。

### 6.4 无声者：天敌

**关系描述**: 无声者与网络是彻底的敌对关系。无声者唯一的目标就是破坏这个网络。

**破坏方式**:
- 渗透中转站，营救受害者
- 收集证据，揭露网络的存在
- 策反网络的低层成员
- 警告潜在目标，打草惊蛇

**对网络的影响**:
> 无声者的存在是网络最大的"运营风险"之一。仅2025年一年，无声者就成功营救了约50名"货物"，并导致三个中转站被警方查获（通过向媒体泄露情报）。

### 6.5 苍白之手：神秘变量

**关系描述**: 未知。

苍白之手与网络的关系是整个毒雾湾最大的谜团之一。没有任何证据表明苍白之手是网络的一部分，也没有任何证据表明他们是网络的敌人。但有以下几点值得关注：

1. 某些被苍白之手"处理"的人，此前曾是网络的成员——包括一些高级成员
2. 苍白之手目击报告中，有几起发生在网络的中转站附近
3. 网络内部有传言称，苍白之手是某些"特殊货物"的最终买家
4. **【同步修正】苍白之手与化工厂的关联**: 苍白之手可能与"灰飞烟灭"事件（1945年化工厂爆炸）存在某种隐秘联系——某些证据表明苍白之手可能在化工厂废墟区建立过早期据点。但苍白之手第一次被**正式目击**是在1997年（见history.md记录），化工厂关联是后来追溯发现的线索。

**理论**:
- 苍白之手是独立于网络运作的另一个犯罪组织？
- 苍白之手是议会的秘密分支，负责处理"特殊问题"？
- 苍白之手是网络的"质量检验员"——在"货物"被出售前进行某种"仪式"？
- 或者，更黑暗的可能性：苍白之手根本不是"人"？

## 7. 网络的脆弱点

### 7.1 已知的弱点

**内部脆弱点**:

1. **信息孤岛**: 网络的每个层级只知道自己的上下线，不了解全貌。这意味着：
   - 一个环节被破坏，不会直接暴露其他环节
   - 但也意味着协调困难，容易出现信任问题

2. **利益冲突**: 不同家族和势力都想从网络中牟利，导致：
   - 内部争斗和背叛
   - "货物"被私吞或转卖
   - 收买对方成员的情况时有发生

3. **底层脆弱**: 最底层的执行者——货源组织者、押送人员——是最脆弱的环节：
   - 他们与"货物"直接接触
   - 他们往往是最容易被收买或威胁的
   - 他们的被捕风险最高

**外部脆弱点**:

1. **无声者渗透**: 无声者正在从内部渗透网络
2. **锈网情报**: 锈网保存着大量网络的历史记录
3. **议会的双刃剑**: 议会需要网络，但网络也是议会最致命的软肋

### 7.2 玩家的机会

基于上述脆弱点，玩家可以采取的策略：

> **风险等级量化定义**：
> - **低风险**：成功率 > 70%
> - **中风险**：成功率 40-70%
> - **高风险**：成功率 < 40%

| 策略 | 目标 | 风险 |
|------|------|------|

## 8. 玩家的位置：为什么是张伟？

### 8.1 玩家角色的多重背景

张伟是一个具有多重背景可能性的角色——无论他最终选择 CIVILIAN（普通人）、AGENT（前特工）还是 MERCENARY（前雇佣兵）背景，这些身份都是张伟可能的"过去"。在"假死"潜伏的三年中，他逐渐将过去的技能、资源和人脉整合为对犯罪网络的复仇力量。

**【同步说明】**: 本节张伟潜伏三年设定与history.md 11.2节、13.1节保持一致。

**2023年：转折点**:
> 一个名叫张伟的中年男子向无声者报告：他的女儿张三妹——一个15岁的女中学生——在学校门口被绑架。三周后，他收到消息，支付了赎金后，女儿被"释放"。但张三妹已经不是原来的那个女孩了。她拒绝说话，拒绝吃饭，拒绝见人。三个月后，她再次"失踪"，这次是无声无息的。

**2023年末：转入地下潜伏**:
> 张伟遭凋亡议会暗杀未遂，在议会放出的"死亡"误导消息掩护下转入地下潜伏。他带着女儿被贩卖的真相消失在毒雾湾的阴影中，在毒雾湾最黑暗的角落蛰伏三年，积蓄力量，等待时机。

**潜伏三年的准备**:
> 张伟在潜伏三年间（2023-2026）准备了详细的调查笔记和反击计划。这些资料记录了女儿被贩卖的完整链条以及犯罪网络的关键弱点。他在黑暗中积蓄力量，指引着2026年的最终反击。

玩家扮演的就是张伟本人——一个在2023年"假死"后潜伏三年的复仇者。凋亡议会以为他已经死了，放出的"死亡"误导消息反而成了他最好的掩护。2026年，张伟决定发动最终反击，他蛰伏三年积蓄的力量将彻底撕裂这个犯罪网络。

根据叙事系统的设定，玩家角色是一位因女儿被贩卖而被迫转入地下的父亲。张伟的调查笔记和反击计划指引着他逐步深入网络的核心。

### 8.2 玩家的独特优势

为什么玩家能够成功——当那么多人失败了？

1. **无私**: 玩家不为金钱，不为权力，只为女儿复仇。这使得玩家难以被收买或威胁。
2. **绝望的动机**: 受害者家属通常在几周内放弃希望，承认失败。但玩家不会。
3. **调查者视角**: 张伟虽然是锈港居民，但作为普通人/前特工/前雇佣兵，他从社会边缘位置发起调查。这意味着他不受犯罪网络内部规则的约束，不属于任何既有的权力结构，能够以"局外人"的眼光审视这个网络的运作逻辑。
4. **时间窗口**: 游戏开始时，网络正处于一个特殊的时间节点——某些变化正在发生，某些旧秩序正在松动。
