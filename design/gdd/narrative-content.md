## 1. 主角语音档案 (Protagonist Voice Profile)

### 1.1 语言风格定位

**核心风格**：硬汉派 + 内心独白型

主角是一位被悲剧压垮的父亲，语言简洁、沉重、富有张力。他的话语克制，但每一个字都带着重量。内心独白则是另一片战场——在那里，愤怒与自责交替嘶咬。

### 1.2 语音特征矩阵

| 维度 | 特征描述 | 示例来源 |
|------|---------|---------|
| **词汇选择** | 短词为主，避免华丽修饰；名词和动词优先 | "你看到了什么？" "够了。" |
| **句子节奏** | 断断续续，常被打断或沉默；大量省略号 | "我知道...但我必须..." |
| **语气** | 低沉、压抑；偶尔爆发；更多是沉默 | 审讯时的冰冷、悲痛时的嘶哑 |
| **标志性表达** | 少量重复的短语，印刻创伤 | "小米..."（呼叫女儿名字）、"她还活着"（自我暗示） |

### 1.3 三种背景的语言差异

#### Civilian（普通人）背景

- 更笨拙的审讯语气，词汇更日常化
- 内心独白更多自我怀疑
- 较少威胁性表达，更多是疲惫的坚持

```
示例对话：
"求你告诉我...我女儿在哪。"
"我不是来伤害你的。我只是...我只想带她回家。"

内心独白：
"我真的有权这样做吗？...不，我必须有权。"
```

#### Agent（特工）背景

- 更专业的审讯技巧，语言精准、简洁
- 内心独白带有分析性，冷酷但有裂痕
- 威胁更加隐蔽，却更令人不寒而栗

```
示例对话：
"你知道规矩。说出来，或者我用别的办法。"
"我有三个问题。你有几个答案？"

内心独白：
"这和以前一样。不，不一样了。这次是为了小米。"
```

#### Mercenary（雇佣兵）背景

- 直接、粗暴、充满暴力暗示
- 内心独白更原始，愤怒驱动
- 威胁是即兴的、不可预测的

```
示例对话：
"我再问一遍。你想用嘴说，还是用血说？"
"你有一条舌头，两条腿。选一个保留。"

内心独白：
"杀他。简单。...不，先问出地址。"
```

### 1.4 主导特质对语音的影响

| 特质 | 对话语气 | 内心独白倾向 |
|------|---------|-------------|
| **DOMINANT_MERCY** | 更温和，有停顿，偶有请求口吻 | 更多同情、自我审视 |
| **DOMINANT_CRUELTY** | 更冰冷，威胁更直接，身体暴力暗示 | 更多愤怒、合理化 |
| **DOMINANT_CALCULATING** | 更理性，像在交易或谈判 | 更多分析、权衡利弊 |
| **DOMINANT_CAUTIOUS** | 更试探性，话语更谨慎 | 更多警觉、等待时机 |

### 1.5 标志性口头禅与表达

**核心口头禅**（所有背景通用）：

- **"小米..."**：呼叫失踪女儿的名字，用于独处或情绪激动时
- **"她还活着"**：自我暗示，在质疑自己时出现
- **"我会找到你"**：对女儿的承诺，独白中使用
- **"别逼我"**：对NPC的警告，暴力的边界线
- **"我知道你在怕什么"**：审讯时使用，显示洞察力

## 2. 核心NPC对话示例 (Core NPC Dialogue Variants)

### 2.1 对话格式规范

每条对话遵循以下格式：
```
[说话者] "{对话内容}" {情感注解/条件}
```

- 对话内容少于120字符
- 使用 {变量名} 作为占位符
- 情感注解描述语音语调

---

### 场景A：玩家进入帮派据点，NPC发现入侵者

#### MERCY变体（玩家主导特质为仁慈）

NPC察觉到入侵者，但注意到玩家的犹豫。

```
[NPC-帮派成员] "等等...你...你不是来杀人的，对吧？"
{声音颤抖，看到玩家没有立即攻击}

[NPC-帮派成员] "我...我只是送货的。我什么都不知道！"
{双手举起，态度软化}

[NPC-帮派成员] "求你了，先生...我有孩子。"
{声音哽咽}
```

#### CRUEL变体（玩家主导特质为残暴）

NPC表现出恐惧，试图逃跑或拼死反击。

```
[NPC-帮派成员] "不...不要过来！"
{声音尖锐，后退撞倒家具}

[NPC-帮派成员] "你会杀我的，对不对？就像杀老陈一样！"
{歇斯底里，抓起附近的武器}

[NPC-帮派成员] "来啊！至少让我死得明白！"
{绝望的挑衅}
```

#### CALCULATING变体（玩家主导特质为计算）

NPC试图谈判或做交易。

```
[NPC-帮派成员] "慢着。你想要什么？情报？钱？"
{双手张开，显示交易意愿}

[NPC-帮派成员] "我知道一些事。关于最近的一批...货物。"
{压低声音，试探性地说}

[NPC-帮派成员] "我可以告诉你地点。换我的命。公平交易。"
{眼神闪烁，等待回应}
```

#### CAUTIOUS变体（玩家主导特质为谨慎）

NPC保持警惕，试探性地接近。

```
[NPC-帮派成员] "你是谁？这里不欢迎外人。"
{手慢慢移向腰间，但未拔枪}

[NPC-帮派成员] "......"
{沉默对视，互相评估}

[NPC-帮派成员] "你不是这边的人。看你的手就知道。"
{指出玩家的不同}
```

### 场景B：玩家放过一个NPC后，该NPC再次出现

NPC记得玩家上次的仁慈（或残忍），反应取决于玩家当时的特质。

#### 场景设定

**触发条件**：玩家曾在第一幕放过NPC（mercy_count > 0），该NPC在后续章节再次出现。

#### MERCY路线NPC反应

```
[旧识NPC-幸存者] "是你...你还活着。"
{声音中带着难以置信的感激}

[旧识NPC-幸存者] "那天你放我走...我一直在想，为什么。"
{走近，但仍保持距离}

[旧识NPC-幸存者] "现在我知道了。你是来找她的，对吧？那个女孩..."
{压低声音} "我也见过她。"
```

#### CRUEL路线NPC反应

```
[旧识NPC-幸存者] "老天...是你。"
{脸色发白，向后退了几步}

[旧识NPC-幸存者] "我以为你会杀光所有人。但你没有杀我。"
{困惑中带着恐惧}

[旧识NPC-幸存者] "求求你别杀我。我什么都没告诉他们。"
{声音颤抖}
```

#### CALCULATING路线NPC反应

```
[旧识NPC-幸存者] "...你果然还在这里。"
{快速评估形势}

[旧识NPC-幸存者] "那天你放了我。这次你想要什么作为交换？"
{直接进入交易模式}

[旧识NPC-幸存者] "我能帮上忙。我知道他们转移的路线。"
{主动提供情报}
```

#### CAUTIOUS路线NPC反应

```
[旧识NPC-幸存者] "我就知道...你还会回来。"
{谨慎地观察四周}

[旧识NPC-幸存者] "你没有杀我。你是哪种人？"
{试图理解玩家动机}

[旧识NPC-幸存者] "...我欠你一条命。这不是我能轻易偿还的。"
{陷入沉默}
```

### 场景C：核心反派首次登场

**场景描述**：玩家追踪到主要反派——"凋亡议会"的影子议长VAREN。首次对峙发生在其私人场所。黑色电影风格：烟雾、阴影、冷静的对话。

> **反派身份说明**: VAREN是凋亡议会公开议长"马库斯·韦恩"的暗面代号。在公众场合，马库斯·韦恩维持着"秩序商人"的体面形象；而VAREN则是他在阴影中的另一个身份——直接指挥执行部门，特别是负责"清理"工作的清道夫。两个身份，同一个人。

#### 对话脚本

```
[反派-VAREN] "你不该来的。"
{背对玩家，声音低沉，从烟雾中逐渐显形}

[反派-VAREN] "或者说...你早就该来了？"
{转过身，眼神冰冷却带着某种审视}

[玩家] "{player_action}"
{玩家选择对话方向}
```

#### 反派VAREN的核心特质表现

```
[反派-VAREN] "你以为你在追什么人？"
{嘲讽的笑} "我只是一个商人。人们需要什么，我就给什么。"

[反派-VAREN] "你女儿？她是商品。最好的那种。"
{毫不掩饰} "但现在...她在哪，只有我知道。"

[反派-VAREN] "想见她？"
{倾身向前} "那你得付出点代价。每个人都得付出代价。"
```

#### 暗示隐藏联系的对话

```
[反派-VAREN] "你的眼神...我见过。"
{停顿，审视玩家}

[反派-VAREN] "{player_name}...不，那不是你的真名，对吧？"
{意味深长地微笑}

[反派-VAREN] "算了。这些都不重要。"
{挥手} "重要的是...我们其实很相似。"

[反派-VAREN] "都是被失去驱动的人。只是我们选择了不同的路。"

[反派-VAREN] "你想知道我是谁？"
{侧身，让身后的灯光勾勒出轮廓}

[反派-VAREN] "有人叫我'议长'。那是我在桌子另一头的名字。"
{声音变得更低沉}

[反派-VAREN] "但在这里...在这个房间...我叫VAREN。"
{意味深长地停顿}

[反派-VAREN] "马库斯·韦恩可以在谈判桌上和你握手。而我..."
{走近一步}

[反派-VAREN] "我来处理那些不该出现在谈判桌上的人。"
```

#### 黑色电影风格的收尾

```
[反派-VAREN] "所以，你现在有两个选择。"
{竖起一根手指} "一，杀了你面前的每一个人，然后继续找。"

[反派-VAREN] "二，坐下来，和我谈谈。"
{拉开一把椅子} "也许你能找到一条更快见到她的路。"

[反派-VAREN] "当然...还有第三个选择。"
{眼神变得危险} "你可以转身离开。假装今天什么都没发生。"

[反派-VAREN] "但我知道你不会选那个。"
{最后一句话是陈述，不是问题}
```

## 3. 内心独白示例 (Inner Monologue Examples)

### 3.1 发现悲剧线索时

**场景**：玩家发现一个遇害的无辜者的遗物——照片、信件、或其他揭示其无辜身份的物品。

#### Civilian背景内心独白

```
"这只手...这只手上有个戒指印。

她结婚了。也许有个丈夫在等她回家。

就像我等小米一样。

...我做了什么？"
```

#### Agent背景内心独白

```
"目标档案显示：林小燕，32岁，会计。

不是目标。是 bystander——无辜者。

任务后评估：可接受损失。
...什么时候变成'可接受'的了？"
```

#### Mercenary背景内心独白

```
"又是一张照片。女人，孩子。

我以前也杀过这种照片里的人吗？

不。别想这个。专注于任务。

...但她丈夫会怎么想？"
```

---

### 3.2 误杀无辜者后

**场景**：LOS系统显示绿色"误杀！"警告，玩家意识到自己杀错了人。

#### 通用核心反应（所有背景）

```
"不...

不。

这不应该发生...这不应该..."
```

#### Civilian背景（自我怀疑加深）

```
"我本来可以问她的。我本来可以...不，我以为...

她是帮凶吗？我不确定。

我不确定。

小米会怎么看她父亲？这样杀人？"
```

#### Agent背景（冷酷面具出现裂痕）

```
"确认误杀。无辜者。

理智惩罚：-15。

...我以前执行过更脏的任务。那时候我什么都没感觉。

现在这是怎么了？

为什么她的脸一直出现在我脑海里？"
```

#### Mercenary背景（愤怒转向自己）

```
"该死。

该死！

我应该更小心。我应该...

她只是个普通人。就像我老婆...

我老婆。我以前的老婆。

我到底在做什么？"
```

---

### 3.3 面对最终抉择时

**场景**：第六章，玩家面对最终反派VAREN，必须做出最终选择——杀死他、放过他、或试图救赎他（揭露他背后的更大阴谋）。

#### DOMINANT_MERCY路线

```
"杀了他...一切就结束了。

但然后呢？然后我变成什么？

小米回来的时候...她能看到什么样的父亲？

一个杀人的人？

不。我已经杀了足够多了。"

最终选择：尝试救赎VAREN，或揭露真相而非私刑
```

#### DOMINANT_CRUELTY路线

```
"他杀了多少人？他让多少家庭破碎？

就像我的家庭一样。

他该死。

每个人都说他该死。

...但我杀他，是因为他该死，还是因为我需要这个出口？"

最终选择：执行私刑，但在扣下扳机前有一瞬间的犹豫
```

#### DOMINANT_CALCULATING路线

```
"杀了他：复仇完成，但网络还在。

放了他：筹码丢失，情报中断。

揭露他：风险最高，但收益...也许是瓦解整个网络。

让我算一下。

...不。没有什么好算的。有些账无法用数字衡量。"

最终选择：揭露真相，利用VAREN作为污点证人
```

#### DOMINANT_CAUTIOUS路线

```
"我已经走到这里了。所有人都死了，只有他还活着。

这说明什么？运气？还是...

不。我知道答案。我一直知道。

我只是想确认。在扣下扳机之前，我想确认自己没有选错。

他会说什么？别人会说什么？

小米会...她会理解我吗？"

最终选择：审慎地处决，或给VAREN一个机会证明自己
```

## 4. 碎片叙事文案 (Fragmented Narrative Content)

### 4.1 环境文本 (Environmental Text)

#### 可交互物件的文字描述

环境文本在玩家悬停或交互时显示，采用第一人称内心视角。

**录音设备类**

```
[旧式录音机]
"录音还在转。按下播放键..."
"——'第三批货出了问题，买家要求退款。
  告诉他，供不应求。
  如果他不满意，让他去找别人。'——
录音到这里断了。"
```

```
[废弃手机]
"手机屏幕碎了，但还能亮。
通知栏里全是借贷软件的催款。
最后一条消息是：'爸爸，我下个月一定还。'
她的女儿...还是他女儿？"
```

**照片与私人物品**

```
[冰箱上的照片]
"一家三口的合影。小女孩举着奖状。

奖状上写着：'小米——期中考试第一名'。

我的小米。

...不。这不是她。但她们差不多大。"
```

```
[血染的日记本]
"日记停在三天前。
'今天又被打了一顿。
他说我不听话。
但我只是问了一句工资的事。'
最后一页只有一行字：'我想回家。'"

{获得线索：受害者是被迫工作者}
```

**医疗记录/文件**

```
[散落的档案]
"一份人口贩卖记录。
'货物清单：
- 3号仓库：女性，18-25岁，状况良好
- 5号仓库：男性，成年，状况一般
- 7号仓库：...'
大部分内容被撕掉了。

但7号仓库旁边有个手写标注：'儿童区'。"
```

### 4.2 录音/对讲机内容 (Audio Logs)

#### 录音脚本1：帮派内部的通讯

```
【录音开始】

[通讯声] "老刘，你他妈怎么办事的？货又少了一个。"

[老刘] "不是我！那个新来的女的——她跑了！"

[通讯声] "跑了？三个看守拦不住一个女的？"

[老刘] "她...她不是普通的...她好像练过。"

[通讯声] "......算了。调监控。找到她，处理掉。
  这批货不能再出事了。"

[通讯声] "还有——那个新来的'买家'，安排一下。
  他要的'特殊货'，今晚送到。"

[录音结束]

{获得线索：有一个女人逃跑了，可能还活着}
{获得线索：有'特殊货物'交易，今晚进行}
```

#### 录音脚本2：反派VAREN的私人记录

```
【录音开始】

[VAREN的声音，低沉而冷静]

"他们以为我是他们的敌人。
不。我不是敌人。
我是清理者。

这座城市每天都在腐烂。我只是...修剪枝条。

有人必须做脏活。
问题是——谁来决定什么是'脏'？

我？

还是那个正在找我的人？

他很有意思。一个父亲。
失去了一切，却还站着。

也许他比我更疯。
也许他比我更清醒。

...让我们看看吧。"

【录音继续——似乎录音者忘了停止】

[翻动纸张的声音]

"...签完这份协议，'议长'那边的戏就演完了。
下周我要去锈港处理些事情。
希望不会太久。"

【录音结束】

{获得线索：VAREN知道玩家的存在}
{获得线索：VAREN与"议长"有关联，暗示是同一人}
{获得线索：VAREN自称'清理者'}
```

#### 录音脚本3：受害者的求救

```
【录音开始】

[女人的声音，颤抖]

"如果有人找到这个...我叫林晓雯。
三个月前，我被骗来这里。他们说...
他们说是合法工作。

这里...这里关着很多人。
女人，孩子。

我们被转了很多次。
最后一次...
是在一个叫'7号仓库'的地方。

求求你们...告诉我的家人...
```

## 5. UI文字规范 (UI Text Standards)

### 5.1 提示文字 (Hint Text)

#### 交互提示

| 场景 | 提示文字 | 风格说明 |
|------|---------|---------|

## 附录：本地化注意事项 (Localization Notes)

### 语气与语调

- 所有对话必须保持一致的压抑、沉重基调
- 中文使用简洁句式，避免过长的复合句
- 内心独白可使用更多省略号和破折号，表示中断和犹豫
- 黑色电影风格需要保持翻译后仍具有"冷峻"感

### 占位符使用规范

| 占位符 | 用途 | 示例 |
|--------|------|------|
| {player_name} | 玩家自定义名称 | "你好，{player_name}" |
| {npc_name} | NPC名称 | "这是{npc_name}" |
| {chapter_number} | 章节编号 | "第{chapter_number}章" |
| {chapter_title} | 章节标题 | "第1章：{chapter_title}" |
| {player_action} | 玩家动作选择 | "保持沉默/发起质问/直接威胁" |
| {location_name} | 地点名称 | "欢迎来到{location_name}" |
| {item_name} | 物品名称 | "你拾取了{item_name}" |
| {daughter_name} | 女儿名字 | "小米..." |

### 字符限制

| 内容类型 | 最大字符数 | 备注 |
|---------|-----------|------|
| 对话行 | 120字符 | 超出自动截断 |
| UI提示 | 60字符 | 简洁明了 |
| NPC名称 | 20字符 | 含空格 |
| 成就名称 | 30字符 | 简洁 |
| 成就描述 | 80字符 | 说明效果 |
| 环境描述 | 200字符 | 可换行 |

### 敏感内容标记

所有涉及以下内容的文本需要额外标记，供本地化团队审查：

- 暴力描述（血液、伤害等）
- 死亡相关（谋杀、自杀等）
- 儿童相关（失踪、贩卖等）
- 政治相关（腐败、体制等）
