## Overview

本文档定义了《断绝：罪恶之源》叙事内容的文案风格指南和内容规范。涵盖主角语音档案、三种对话变体的语言特征、碎片化叙事策略，以及VAREN身份揭示机制。本文档是叙事系统（narrative-system.md）的下游内容规范，为编剧团队提供统一的写作参考。

## Player Fantasy

玩家在游戏中通过主角的语音和内心独白体验一个被悲剧压垮但仍坚持追寻真相的父亲形象。主角的语言简洁克制但充满张力——审讯时的冰冷、悲痛时的嘶哑、以及愤怒时的危险沉默。碎片化的叙事方式让玩家在收集线索的过程中逐步拼凑真相，获得解谜般的叙事满足感。

## 1. 主角语音档案 (Protagonist Voice Profile)

### 1.1 语言风格定位

**核心风格**：硬汉派 + 内心独白型

主角是一位被悲剧压垮的父亲，语言简洁、沉重、富有张力。他的话语克制，但每一个字都带着重量。内心独白则是另一片战场——在那里，愤怒与自责交替嘶咬。

### 1.2 语音特征矩阵

| 维度 | 特征描述 | 示例来源 |
|------|---------|---------|
| **词汇选择** | 短词为主，避免华丽修饰；名词和动词优先 | "你看到了什么？" "够了。" |
| **句子节奏** | 断断续续，常被打断或沉默；大量省略号 | "我知道...但我必须..." |
| **语气** | 低沉、压抑；偶尔爆发；更多是沉默 | 审讯时的冰冷、悲痛时的嘶哑 |
| **标志性表达** | 少量重复的短语，印刻创伤 | "小米..."（呼叫女儿名字）、"她还活着"（自我暗示） |

### 1.3 三种背景的语言差异

#### Civilian（普通人）背景

- 更笨拙的审讯语气，词汇更日常化
- 内心独白更多自我怀疑
- 较少威胁性表达，更多是疲惫的坚持

```
示例对话：
"求你告诉我...我女儿在哪。"
"我不是来伤害你的。我只是...我只想带她回家。"

内心独白：
"我真的有权这样做吗？...不，我必须有权。"
```

#### Agent（特工）背景

- 更专业的审讯技巧，语言精准、简洁
- 内心独白带有分析性，冷酷但有裂痕
- 威胁更加隐蔽，却更令人不寒而栗

```
示例对话：
"你知道规矩。说出来，或者我用别的办法。"
"我有三个问题。你有几个答案？"

内心独白：
"这和以前一样。不，不一样了。这次是为了小米。"
```

#### Mercenary（雇佣兵）背景

- 直接、粗暴、充满暴力暗示
- 内心独白更原始，愤怒驱动
- 威胁是即兴的、不可预测的

```
示例对话：
"我再问一遍。你想用嘴说，还是用血说？"
"你有一条舌头，两条腿。选一个保留。"

内心独白：
"杀他。简单。...不，先问出地址。"
```

### 1.4 主导特质对语音的影响

| 特质 | 对话语气 | 内心独白倾向 |
|------|---------|-------------|
| **DOMINANT_MERCY** (MERCY) | 更温和，有停顿，偶有请求口吻 | 更多同情、自我审视 |
| **DOMINANT_CRUELTY** | 更冰冷，威胁更直接，身体暴力暗示 | 更多愤怒、合理化 |
| **DOMINANT_CALCULATING** | 更理性，像在交易或谈判 | 更多分析、权衡利弊 |
| **DOMINANT_CAUTIOUS** | 更试探性，话语更谨慎 | 更多警觉、等待时机 |

### 1.5 背景 × 主导特质交叉语境规则

当背景（Civilian/Agent/Mercenary）与主导特质（DOMINANT_MERCY/DOMINANT_CRUELTY/DOMINANT_CALCULATING/DOMINANT_CAUTIOUS）组合时，按以下优先级规则确定对话风格：

> **优先级规则**：背景作为**语气基础层**，主导特质作为**语气修饰层**。背景决定词汇选择和句子结构的基准线，主导特质决定情感色彩和表达策略。

| 背景 | + 特质 | 对话风格描述 | 示例场景 |
|------|--------|-------------|---------|
| **Civilian** | + MERCY | 笨拙的仁慈，充满自我怀疑但坚持人性 | "我不想伤害你...但我必须知道她在哪。" |
| **Civilian** | + CRUELTY | 压抑的愤怒突然爆发，言辞粗糙但缺乏专业感 | "你他妈...闭嘴。我不想听。" |
| **Civilian** | + CALCULATING | 笨拙但努力保持理性，像普通人尝试"冷静谈判" | "我们可以...做个交易。你说个数。" |
| **Civilian** | + CAUTIOUS | 高度警觉，试探性极强，话语充满犹豫 | "你...你知道些什么？慢慢说..." |
| **Agent** | + MERCY | 冷酷面具下的裂缝，专业但带有不寻常的停顿 | "配合我，你活。不配合...我也理解。" |
| **Agent** | + CRUELTY | 冰冷的专业威胁，分析性的暴力暗示 | "你的骨密度在第7秒会开始下降。逃不掉的。" |
| **Agent** | + CALCULATING | 冷酷的交易者，精准的语言把控 | "你有30秒。15秒用来决定，15秒用来签字。" |
| **Agent** | + CAUTIOUS | 极度谨慎，观察优先，话语精准但不透露意图 | "我问你答。没有问题，只有确认。" |
| **Mercenary** | + MERCY | 笨拙的仁慈，与其凶狠本性形成冲突的尴尬感 | "我不想杀你...但你得给我一个不杀的理由。" |
| **Mercenary** | + CRUELTY | 直接的暴力威胁，不可预测的残忍 | "我会把你的膝盖骨放在你手边。想好了再动。" |
| **Mercenary** | + CALCULATING | 即兴的交易谈判，直觉的经济思维 | "这多少钱？你这条命值多少？我开个价。" |
| **Mercenary** | + CAUTIOUS | 危险人物的沉默观察，静默比话语更有压迫感 | "......"（沉默地盯着目标，等待对方先开口） |

> **实现注意**：编剧在创作具体对话时，首先根据背景确定**基础语气**（词汇难度、句子复杂度、威胁风格），然后根据主导特质添加**情感色彩修饰**。如果两者产生冲突，以背景为基础，以特质为修饰。

### 1.6 标志性口头禅与表达

**核心口头禅**（所有背景通用）：

- **"小米..."**：呼叫失踪女儿的名字，用于独处或情绪激动时
- **"她还活着"**：自我暗示，在质疑自己时出现
- **"我会找到你"**：对女儿的承诺，独白中使用
- **"别逼我"**：对NPC的警告，暴力的边界线
- **"我知道你在怕什么"**：审讯时使用，显示洞察力

## 2. 核心NPC对话示例 (Core NPC Dialogue Variants)

### 2.1 对话格式规范

每条对话遵循以下格式：
```
[说话者] "{对话内容}" {情感注解/条件}
```

- 对话内容少于120字符
- 使用 {变量名} 作为占位符
- 情感注解描述语音语调

---

### 场景A：玩家进入帮派据点，NPC发现入侵者

#### MERCY变体（玩家主导特质为仁慈）

NPC察觉到入侵者，但注意到玩家的犹豫。

```
[NPC-帮派成员] "等等...你...你不是来杀人的，对吧？"
{声音颤抖，看到玩家没有立即攻击}

[NPC-帮派成员] "我...我只是送货的。我什么都不知道！"
{双手举起，态度软化}

[NPC-帮派成员] "求你了，先生...我有孩子。"
{声音哽咽}
```

#### CRUEL变体（玩家主导特质为残暴）

NPC表现出恐惧，试图逃跑或拼死反击。

```
[NPC-帮派成员] "不...不要过来！"
{声音尖锐，后退撞倒家具}

[NPC-帮派成员] "你会杀我的，对不对？就像杀老陈一样！"
{歇斯底里，抓起附近的武器}

[NPC-帮派成员] "来啊！至少让我死得明白！"
{绝望的挑衅}
```

#### CALCULATING变体（玩家主导特质为计算）

NPC试图谈判或做交易。

```
[NPC-帮派成员] "慢着。你想要什么？情报？钱？"
{双手张开，显示交易意愿}

[NPC-帮派成员] "我知道一些事。关于最近的一批...货物。"
{压低声音，试探性地说}

[NPC-帮派成员] "我可以告诉你地点。换我的命。公平交易。"
{眼神闪烁，等待回应}
```

#### CAUTIOUS变体（玩家主导特质为谨慎）

NPC保持警惕，试探性地接近。

```
[NPC-帮派成员] "你是谁？这里不欢迎外人。"
{手慢慢移向腰间，但未拔枪}

[NPC-帮派成员] "......"
{沉默对视，互相评估}

[NPC-帮派成员] "你不是这边的人。看你的手就知道。"
{指出玩家的不同}
```

### 场景B：玩家放过一个NPC后，该NPC再次出现

NPC记得玩家上次的仁慈（或残忍），反应取决于玩家当时的特质。

#### 场景设定

**触发条件**：玩家曾在第一幕放过NPC（mercy_count > 0），该NPC在后续章节再次出现。

#### MERCY路线NPC反应

```
[旧识NPC-幸存者] "是你...你还活着。"
{声音中带着难以置信的感激}

[旧识NPC-幸存者] "那天你放我走...我一直在想，为什么。"
{走近，但仍保持距离}

[旧识NPC-幸存者] "现在我知道了。你是来找她的，对吧？那个女孩..."
{压低声音} "我也见过她。"
```

#### CRUEL路线NPC反应

```
[旧识NPC-幸存者] "老天...是你。"
{脸色发白，向后退了几步}

[旧识NPC-幸存者] "我以为你会杀光所有人。但你没有杀我。"
{困惑中带着恐惧}

[旧识NPC-幸存者] "求求你别杀我。我什么都没告诉他们。"
{声音颤抖}
```

#### CALCULATING路线NPC反应

```
[旧识NPC-幸存者] "...你果然还在这里。"
{快速评估形势}

[旧识NPC-幸存者] "那天你放了我。这次你想要什么作为交换？"
{直接进入交易模式}

[旧识NPC-幸存者] "我能帮上忙。我知道他们转移的路线。"
{主动提供情报}
```

#### CAUTIOUS路线NPC反应

```
[旧识NPC-幸存者] "我就知道...你还会回来。"
{谨慎地观察四周}

[旧识NPC-幸存者] "你没有杀我。你是哪种人？"
{试图理解玩家动机}

[旧识NPC-幸存者] "...我欠你一条命。这不是我能轻易偿还的。"
{陷入沉默}
```

### 场景C：核心反派首次登场

**场景描述**：玩家追踪到主要反派——"凋亡议会"的影子议长VAREN。首次对峙发生在其私人场所。黑色电影风格：烟雾、阴影、冷静的对话。

> **反派身份说明**: VAREN是凋亡议会公开议长"马库斯·韦恩"的暗面代号。在公众场合，马库斯·韦恩维持着"秩序商人"的体面形象；而VAREN则是他在阴影中的另一个身份——直接指挥执行部门，特别是负责"清理"工作的清道夫。两个身份，同一个人。

#### 对话脚本

```
[反派-VAREN] "你不该来的。"
{背对玩家，声音低沉，从烟雾中逐渐显形}

[反派-VAREN] "或者说...你早就该来了？"
{转过身，眼神冰冷却带着某种审视}

[玩家] "{player_response}"
{玩家选择对话方向}
```

#### 反派VAREN的核心特质表现

```
[反派-VAREN] "你以为你在追什么人？"
{嘲讽的笑} "我只是一个商人。人们需要什么，我就给什么。"

[反派-VAREN] "你女儿？她是商品。最好的那种。"
{毫不掩饰} "但现在...她在哪，只有我知道。"

[反派-VAREN] "想见她？"
{倾身向前} "那你得付出点代价。每个人都得付出代价。"
```

#### 暗示隐藏联系的对话

```
[反派-VAREN] "你的眼神...我见过。"
{停顿，审视玩家}

[反派-VAREN] "{player_name}...不，那不是你的真名，对吧？"
{意味深长地微笑}

[反派-VAREN] "算了。这些都不重要。"
{挥手} "重要的是...我们其实很相似。"

[反派-VAREN] "都是被失去驱动的人。只是我们选择了不同的路。"

[反派-VAREN] "你想知道我是谁？"
{侧身，让身后的灯光勾勒出轮廓}

[反派-VAREN] "有人叫我'议长'。那是我在桌子另一头的名字。"
{声音变得更低沉}

[反派-VAREN] "但在这里...在这个房间...我叫VAREN。"
{意味深长地停顿}

[反派-VAREN] "马库斯·韦恩可以在谈判桌上和你握手。而我..."
{走近一步}

[反派-VAREN] "我来处理那些不该出现在谈判桌上的人。"
```

#### 黑色电影风格的收尾

```
[反派-VAREN] "所以，你现在有两个选择。"
{竖起一根手指} "一，杀了你面前的每一个人，然后继续找。"

[反派-VAREN] "二，坐下来，和我谈谈。"
{拉开一把椅子} "也许你能找到一条更快见到她的路。"

[反派-VAREN] "当然...还有第三个选择。"
{眼神变得危险} "你可以转身离开。假装今天什么都没发生。"

[反派-VAREN] "但我知道你不会选那个。"
{最后一句话是陈述，不是问题}
```

## 3. 内心独白示例 (Inner Monologue Examples)

### 3.1 发现悲剧线索时

**场景**：玩家发现一个遇害的无辜者的遗物——照片、信件、或其他揭示其无辜身份的物品。

#### Civilian背景内心独白

```
"这只手...这只手上有个戒指印。

她结婚了。也许有个丈夫在等她回家。

就像我等小米一样。

...我做了什么？"
```

#### Agent背景内心独白

```
"目标档案显示：林小燕，32岁，会计。

不是目标。是 bystander——无辜者。

任务后评估：可接受损失。
...什么时候变成'可接受'的了？"
```

#### Mercenary背景内心独白

```
"又是一张照片。女人，孩子。

我以前也杀过这种照片里的人吗？

不。别想这个。专注于任务。

...但她丈夫会怎么想？"
```

---

### 3.2 误杀无辜者后

**场景**：LOS系统标记NPC身份后，Gritty Takedowns显示警告，玩家意识到自己杀错了人。

#### 通用核心反应（所有背景）

```
"不...

不。

这不应该发生...这不应该..."
```

#### Civilian背景（自我怀疑加深）

```
"我本来可以问她的。我本来可以...不，我以为...

她是帮凶吗？我不确定。

我不确定。

小米会怎么看她父亲？这样杀人？"
```

#### Agent背景（冷酷面具出现裂痕）

```
"确认误杀。无辜者。

理智惩罚：-15。

...我以前执行过更脏的任务。那时候我什么都没感觉。

现在这是怎么了？

为什么她的脸一直出现在我脑海里？"
```

#### Mercenary背景（愤怒转向自己）

```
"该死。

该死！

我应该更小心。我应该...

她只是个普通人。就像我老婆...

我老婆。我以前的老婆。

我到底在做什么？"
```

---

### 3.3 面对最终抉择时

**场景**：第六章，玩家面对最终反派VAREN，必须做出最终选择——杀死他、放过他、或试图救赎他（揭露他背后的更大阴谋）。

#### MERCY路线 (DOMINANT_MERCY)

```
"杀了他...一切就结束了。

但然后呢？然后我变成什么？

小米回来的时候...她能看到什么样的父亲？

一个杀人的人？

不。我已经杀了足够多了。"

最终选择：尝试救赎VAREN，或揭露真相而非私刑
```

#### DOMINANT_CRUELTY路线

```
"他杀了多少人？他让多少家庭破碎？

就像我的家庭一样。

他该死。

每个人都说他该死。

...但我杀他，是因为他该死，还是因为我需要这个出口？"

最终选择：执行私刑，但在扣下扳机前有一瞬间的犹豫
```

#### DOMINANT_CALCULATING路线

```
"杀了他：复仇完成，但网络还在。

放了他：筹码丢失，情报中断。

揭露他：风险最高，但收益...也许是瓦解整个网络。

让我算一下。

...不。没有什么好算的。有些账无法用数字衡量。"

最终选择：揭露真相，利用VAREN作为污点证人
```

#### DOMINANT_CAUTIOUS路线

```
"我已经走到这里了。所有人都死了，只有他还活着。

这说明什么？运气？还是...

不。我知道答案。我一直知道。

我只是想确认。在扣下扳机之前，我想确认自己没有选错。

他会说什么？别人会说什么？

小米会...她会理解我吗？"

最终选择：审慎地处决，或给VAREN一个机会证明自己
```

## 4. 碎片叙事文案 (Fragmented Narrative Content)

### 4.1 环境文本 (Environmental Text)

#### 可交互物件的文字描述

环境文本在玩家悬停或交互时显示，采用第一人称内心视角。

**录音设备类**

```
[旧式录音机]
```

## 7. 边界情况 (Edge Cases)

### 7.1 占位符未填充

**情况**：运行时 `{player_name}`、`{npc_name}` 等占位符无对应数据时。

**处理规则**（不允许显示原始占位符字符串）：

| 占位符 | 降级值 | 说明 |
|--------|--------|------|
| `{player_name}` | "你" | 通用人称，不破坏语气 |
| `{npc_name}` | "陌生人" | 保持黑色电影氛围 |
| `{daughter_name}` | "小米" | 剧情锚定，固定值，不可配置 |
| `{player_action}` | 不出现在玩家可见UI中 | 仅用于脚本内部标注，策划填写时不得用于公开文本 |
| `{location_name}` | "这里" | 通用地点指代 |
| `{item_name}` | "某物" | 降级后触发系统日志警告，便于QA发现 |

### 7.2 对话行超过字符限制

**情况**：本地化翻译版本（英文/日文等）字符数超出 `dialogue_line_char_limit`（默认120）。

**处理**：UI System 在最近完整单词或句子边界处软截断，并在末尾追加省略号 `...`。中文原版内容由策划严格控制在限制内，不依赖自动截断；若中文版仍超出，视为内容错误，交还策划修改。

### 7.3 无主导特质（特质分布均等）

**情况**：玩家四项特质值相等或差距低于判定阈值，`CalculateDominantTrait` 返回 `NONE`。

**处理**：对话系统回退至 `CAUTIOUS` 变体（安全降级，最保守、最不破坏剧情逻辑的选项）。若该 NPC 对话未定义 `CAUTIOUS` 变体，则进一步降级至 `NEUTRAL` 通用文本。降级优先级参见 Narrative System Section 3.6.1。

### 7.4 场景B再现对话触发失败

**情况**：`mercy_count > 0` 条件满足，但 NPC 实体未正确关联历史记录（如存档损坏、NPC ID 变更）。

**处理**：回退至首次见面的 `CAUTIOUS` 变体，避免出现"你认识我"却没有历史背景的剧情矛盾。

**数据补偿机制**：
当检测到 `mercy_count > 0` 但 NPC 历史记录丢失时，系统自动触发以下补偿：
1. **闪回补偿片段**：在回退对话前，播放简短回忆片段（内容从玩家历史 merccy_count 事件中随机选取一条代表性场景，约3-5秒）。**闪回内容来源**：`{player_name}在[章节]放过了[NPC名称]` 格式文本，由Narrative System生成。
2. **线索碎片补偿**：给予 1 条背景线索碎片（类型为 `compensation_fragment`，重要性为 `TRIVIAL`），内容为通用背景信息（如"这个城市的某些人值得被原谅"），确保玩家不会因技术问题错过关键剧情。
3. **日志特殊标记**：在日志中该 NPC 条目显示 `[补偿] 历史记录丢失 — 您之前的仁慈选择已被记录`，NPC态度仍基于 `mercy_count > 0` 计算（不受记录丢失影响）。

> **设计意图**：即使因技术问题导致历史记录丢失，玩家因仁慈选择而获得的剧情价值不会完全丧失。闪回片段承认了玩家过去的道德选择，保留了"选择有重量"的主题。

### 7.5 敏感内容区域限制

**情况**：部分发行地区需要软化或删除涉及儿童、极端暴力等的特定内容。

**处理**：所有在附录"敏感内容标记"列表中的文本块，策划必须同步提供 `_ALT` 后缀备用版本（内容弱化但语义不变）。原版内容强度不减，由各地区发行商在构建时选择主版或 `_ALT` 版。

### 7.6 VAREN双重身份提前暴露

**情况**：玩家在剧情设计的揭露节点前，通过环境文本或录音脚本中的线索标注，推断出"议长=VAREN"。

**处理**：这属于设计意图内的"玩家洞察力奖励"，不视为剧情泄露。线索系统仅记录线索获取，不主动破坏悬念。

**正式揭露事件的触发条件**：

| 触发时机 | 触发条件 | 触发方式 |
|---------|---------|---------|
| **第3章 VAREN 首次对峙（场景C）** | 必须满足以下条件之一：<br>• 玩家**实际获得** ≥2 条指向 VAREN-议长关联的线索（线索在 `clue-and-journal.md` 中预设 `criticality = CRITICAL`，且已被 Clue & Journal 系统添加到玩家线索日志）<br>• 完成第3章所有调查任务 | Narrative System 在第3章场景C开始时检查条件。**说明**："获得"指玩家已解锁并添加到线索日志的线索，不是场景中存在的线索。触发检查时调用 `ClueJournal.HasClueWithTag("VAREN-议长关联", min_critical_count=2)` 验证。 |

**提前推断的处理**：
- 如果玩家通过环境文本/录音脚本提前推断出 VAREN 身份，允许解锁**部分 VAREN 对话分支**（体现玩家的洞察力）
- 但正式的"VAREN身份确认"成就/moral flag **必须在第3章场景C触发**
- 线索积累不跳过该事件，但玩家可以因为提前推断而在第3章获得额外的对话选项

**设计意图**：玩家的洞察力得到奖励（提前解锁部分对话），但正式的身份揭露保持叙事张力。"你知道真相，但你不知道全部"——这是黑色电影的核心魅力。

## 8. 系统依赖 (Dependencies)

### 8.1 依赖关系概览

本文档定义的叙事内容资产被以下系统消费，数据单向从内容层流向运行时系统：

```
narrative-content.md（内容资产库）
         ↓ 提供文字资产
┌──────────────┬─────────────┬──────────────────┬─────────────────┐
│ NPC AI System │  UI System  │ Narrative System  │ Sanity/Rage Meter│
└──────────────┴─────────────┴──────────────────┴─────────────────┘
```

### 8.2 与 NPC AI System 的接口

| 方向 | 内容 | 说明 |
|------|------|------|
| 本文档 → NPC AI | 对话树文字数据 | 本文档中的对话脚本由策划按 `DialogueTreeConfig` 格式录入 `assets/data/dialogue/` |
| NPC AI → 本文档（消费） | `player_background` 枚举值 | 对话变体选择依赖 `CIVILIAN / AGENT / MERCENARY` |
| NPC AI → 本文档（消费） | `dominant_trait` 枚举值 | 变体选择依赖 `DOMINANT_MERCY / DOMINANT_CRUELTY / DOMINANT_CALCULATING / DOMINANT_CAUTIOUS` |

接口协议参考：`design/gdd/dialog-tree-interface.md`

### 8.3 与 Narrative System 的接口

| 方向 | 内容 | 说明 |
|------|------|------|
| Narrative System → 本文档（条件输入） | `mercy_count`、`victim_kill_count`、`moral_standing` | 控制条件对话触发（如场景B再现对话） |
| 本文档 → Narrative System（事件标注） | `{获得线索：...}` 标注 | 内容脚本中的标注由 Narrative System 解析并触发 `ClueDiscoveredEvent` |
| 本文档 → Narrative System（事件标注） | `{触发支线任务：...}` 标注 | 触发 `QuestStartedEvent`，任务数据定义归属 Narrative System |

接口协议参考：`design/gdd/narrative-system.md`

### 8.4 与 UI System 的接口

| 方向 | 内容 | 说明 |
|------|------|------|
| 本文档 → UI System | 字符限制规范（第5节 & 附录字符限制表） | UI System 文本渲染组件按本文档定义的上限裁切 |
| 本文档 → UI System | HUD元素文字、提示文字、警告文字内容 | UI System 从 `assets/data/ui-text/` 读取，本文档为内容来源 |
| UI System → 本文档（运行时替换） | 键位占位符 `{交互键}` 的实际按键名 | UI System 在运行时将占位符替换为平台对应键位 |

接口协议参考：`design/gdd/ui-system.md`

### 8.5 与 Sanity/Rage Meter 的接口

| 方向 | 内容 | 说明 |
|------|------|------|
| Sanity/Rage → 本文档（触发条件） | 理智值/愤怒值阈值状态 | 低理智/高愤怒状态下触发对应的内心独白变体 |
| 本文档 → Sanity/Rage | 无直接数据流 | 本文档仅提供文字内容资产，触发时机由 Sanity/Rage 系统决定 |

接口协议参考：`design/gdd/sanity-rage-meter.md`

### 8.6 反向依赖（依赖本文档的系统）

| 系统 | 依赖内容 |
|------|---------|
| `narrative-system.md` | 对话变体框架结构、`{获得线索}` / `{触发支线任务}` 标注格式规范 |
| `npc-ai-system.md` | 对话树数据内容、背景与特质枚举的文字对应关系 |
| `ui-system.md` | 字符限制规范、HUD / 提示 / 警告文字规范 |
| `level-narrative-ch1.md` | 场景A / B / C 对话脚本及触发条件说明 |

## 9. 调参旋钮 (Tuning Knobs)

所有调参数值存储于 `assets/data/narrative-content-config.json`，不在代码中硬编码。

| 参数名 | 类型 | 默认值 | 安全范围 | 分类 | 影响内容 |
|--------|------|--------|---------|------|---------|
| `dialogue_line_char_limit` | int | 120 | 80–160 | Gate | 对话框单行最大字符数；低于80影响信息密度，高于160超出对话框UI边界 |
| `ui_hint_char_limit` | int | 60 | 40–80 | Gate | 交互提示文字最大字符数 |
| `achievement_name_char_limit` | int | 30 | 20–40 | Gate | 成就名称最大字符数 |
| `achievement_desc_char_limit` | int | 80 | 60–100 | Gate | 成就描述最大字符数 |
| `env_text_char_limit` | int | 200 | 150–300 | Gate | 环境文本（物件描述）最大字符数 |
| `npc_name_char_limit` | int | 20 | 10–30 | Gate | NPC显示名称最大字符数（含空格） |
| `monologue_display_duration_ms` | int | 3500 | 2000–6000 | Feel | 内心独白单条文字在屏幕上的显示时长（毫秒）；过短玩家来不及阅读，过长破坏节奏 |
| `loading_tip_fade_duration_ms` | int | 800 | 400–1500 | Feel | 加载界面提示文字淡入淡出时长 |
| `moral_warning_display_duration_ms` | int | 2000 | 1500–3000 | Feel | 道德警告文字持续显示时长；低于1500会被玩家忽视 |
| `dominant_trait_fallback` | enum | `CAUTIOUS` | `MERCY` / `CAUTIOUS` | Gate | 无主导特质时的对话变体降级目标；选 CAUTIOUS 而非 MERCY 是因为谨慎更中性，不过早暗示道德立场 |

## 10. 验收标准 (Acceptance Criteria)

### 10.1 功能性验收

| 标准ID | 测试项 | 通过条件 | 测试方法 |
|--------|--------|---------|---------|
| AC-NC-01 | 对话变体按主导特质正确切换 | `dominant_trait = DOMINANT_MERCY` 时场景A显示MERCY变体；四种特质各自独立验证 | 分别设置四种特质值，进入场景A，对比变体文本内容 |
| AC-NC-02 | 背景对话差异正确加载 | AGENT背景对话包含分析性语言（"我有三个问题"类）；CIVILIAN背景包含笨拙语气（"我不是来伤害你的"类） | 创建三个存档分别选三种背景，对比同一NPC对话内容 |
| AC-NC-03 | 场景B再现对话触发条件正确 | 放过NPC后（`mercy_count > 0`），后续章节该NPC使用"再现对话"脚本而非首次见面脚本 | 放过NPC → 进入后续章节 → 验证NPC台词与场景B脚本一致 |
| AC-NC-04 | 线索标注正确触发线索系统 | 玩家读取含 `{获得线索}` 标注的录音/文件后，Clue&Journal 系统新增对应线索条目 | 播放录音脚本1/2/3，检查线索日志新增条目名称与脚本标注一致 |
| AC-NC-05 | 字符限制生效 | 所有对话行实际显示字符数不超过120（`dialogue_line_char_limit` 默认值） | 自动化扫描 `assets/data/dialogue/` 所有JSON文件，断言最长文本行字符数 ≤ 120 |
| AC-NC-06 | 占位符降级处理正确 | `player_name` 为空时对话显示"你"而非原始占位符字符串 `{player_name}` | 清空存档 player_name 字段，进入对话场景，验证显示文本 |

> **降级策略说明**：当 `player_name` 为空时，使用"你"作为降级值是经过考虑的沉浸感权衡：
> - **优势**：避免了占位符字符串 `{player_name}` 破坏沉浸感
> - **局限**：在NPC对玩家说话时（"你还好吗？"）使用"你"是正确的，但在玩家内心独白时（"我必须找到她"）使用"你"可能轻微破坏沉浸感
> - **MVP决策**：为避免占位符问题，选择接受轻微的内心独白不一致。这是 MVP 阶段的合理权衡，Full Vision 阶段可考虑为内心独白对话使用不同的占位符格式（如 `{player_name}对自己说`）
| AC-NC-07 | 支线任务触发标注生效 | 完整播放碎片4（失踪者家属）对话后，任务日志出现"寻找失踪者小雨" | 播放碎片4对话，检查任务日志 |
| AC-NC-08 | 成就文字正确显示 | 触发 `ACH_MERCY_01` 时，成就弹窗名称为"仁慈之人"，解锁文字为"你选择了宽恕。这是一种力量。" | 放过10个NPC后验证成就弹窗全部字段 |
| AC-NC-09 | 道德警告文字按身份分类正确显示 | 击杀Unknown显示红色全屏警告；击杀Victim显示"误杀！"绿转红渐变；击杀Accomplice显示黄色警告 | 分别击杀三种不同身份NPC，对比警告文字内容与样式 |
| AC-NC-10 | VAREN双重身份线索同步解锁 | 播放录音脚本2后，"VAREN知道玩家存在"与"VAREN与议长有关联"两条线索同时出现在线索日志 | 播放VAREN私人录音，验证线索日志新增两条独立条目 |

### 10.2 体验性验收（需游戏测试主观验证）

| 标准 | 判断方法 | 合格目标 |
|------|---------|---------|
| 背景语气差异化 | 5位测试玩家在不看背景设定的情况下，通过对话辨别当前主角背景（AGENT / CIVILIAN / MERCENARY） | 正确率不低于70% |
| 内心独白共情度 | 测试玩家在"误杀无辜者"场景后，反馈内心独白"传达了真实的愧疚感" | 反馈比例不低于60% |
| VAREN登场节奏 | 场景C"核心反派首次登场"对话全程无玩家主动跳过；测试后玩家能复述VAREN的核心性格特点 | 零跳过率；性格复述准确率不低于80% |
| 环境文本信息密度 | 测试玩家读完一段环境文本后能清晰描述"这里发生了什么"，且无"信息太多"反馈 | 描述准确率不低于75%；信息过量投诉率低于10% |
