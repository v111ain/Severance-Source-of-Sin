## 2. 叙事背景

### 2.1 故事发生背景

**物理空间**：城市边缘的一座废弃货运站，曾是合法的物流中转站，十五年前因资金链断裂废弃。现被黑帮"铁钩帮"（Ironhook Gang）接管为秘密据点——表面是流浪汉的临时收容所，实际是人口贩卖路线的转运点。

**为何选择此处**：
- 玩家获得的第一个线索指向这里
- 这是一个"灰色地带"——合法与非法、受害者与帮凶的边界模糊
- 地理位置偏僻，但足够"日常"，让玩家感受到罪恶就在身边

### 2.2 与主线的关联

**提供的答案**：
- 确认女儿还活着（被"单独处理"而非"处理掉"）
- 确认这不是随机事件（她是目标性绑架）
- 确认帮派知道有人在查她

**引发的新疑问**：
- 为什么帮派要"亲自处理"女儿？她知道了什么？
- 谁给玩家发的匿名线索？
- "铁钩"是什么意思？

### 2.3 情感弧线

| 阶段 | 情绪状态 | 驱动力 |
|------|----------|--------|
| **进入** | 警觉、压抑的愤怒 | "线索把我带到这里。女儿失踪48小时后。" |
| **探索** | 焦虑上升 → 恶心 → 恐惧 | 发现尸体/窃听到关于"女孩"的对话 |
| **深入** | 道德模糊 → 冷血决心 | 确认女儿是目标、意识到系统性的恶 |
| **撤离** | 疲惫、黑暗的满足、新的疑问 | "我知道得更多了。但还不够。" |

## 5. 监听点设计

```
位置: 入口院落西侧阴影 (1, 9)

可监听目标: G4(门卫) + A1(瘾君子)

可窃听对话内容:

  G4: "今天外面没什么动静..."
  A1: "老大，今天的货什么时候到..."

  A1: "我需要钱买粉...要不我偷偷放一个人出去？"

## 6. 环境处决点

### 6.1 环境处决点 #1: 灭火器 (主院落)

```
位置: 主院落东侧墙壁 (11, 9)
物件类型: 爆炸类 (Explosive)

位置战术价值:
  - 位于G1巡逻路线旁
  - 玩家可从掩体(储物架)后方接近
  - 灭火器爆炸可影响半径8米内的NPC

利用方式:
  1. 玩家潜行至灭火器旁
  2. 触发"待命"状态(持有)
  3. 当G1巡逻至位置(10, 9)时
  4. 长按放置在G1必经之路
  5. 引爆 - G1受到致命伤害
  6. 爆炸声吸引G2/G3注意，创造行动窗口

无声击杀条件:
  - 使用消音射击远程引爆(不暴露位置)
  - 或在G1进入SEARCH状态后引爆(掩盖声源)
```

### 6.2 环境处决点 #2: 悬挂重物 (仓库A)

```
位置: 仓库A入口横梁 (7, 13)
物件类型: 障碍类 (Obstacle) - 可转换为致命陷阱

位置战术价值:
  - 横跨仓库A入口
  - A2(帮凶)经常在入口附近工作
  - V1(受害者)被绑在附近

利用方式:
  1. 玩家潜行至横梁下方
  2. 触发"切割"动作(需要工具刀或特定按键)
  3. 重物下落，击中下方NPC
  4. 击晕或击杀取决于NPC位置

无声击杀条件:
  - 必须等目标进入落点区域
  - 无法远程触发
  - 适合对付低警觉的A2
```

## 7. 玩家动线

### 7.1 最优路径（推荐）

```
[起点] → 入口院落(监听点1) → 主院落(监听点2) → 仓库A(救V1) →
主院落(处决点1) → 仓库B(救V2) → 办公室(监听点3) → 屋顶撤离
```

| 阶段 | 路线 | 行动 |
|------|------|------|
| 1 | 入口铁丝网 → 岗亭阴影 | 利用掩体潜入，监听G4和A1 |
| 2 | 沿墙根 → 废弃货车 | 移动至主院落，监听G1和G2 |
| 3 | 货车底部 → 仓库A入口 | 趁G1巡逻间隙潜入仓库A |
| 4 | 仓库A货架后 → V1位置 | 解救受害者V1，获取情报 |
| 5 | 仓库A → 主院落东侧 | 利用灭火器处决G1或绕开 |
| 6 | 主院落 → 仓库B走廊 | 利用G1死亡制造的混乱潜入 |
| 7 | 仓库B → V2位置 | 解救受害者V2(疑似女儿) |
| 8 | 仓库B → 屋顶 | 清除/绕过G2，抵达撤离点 |

**预估时间**: 3-4分钟(潜行型) / 2-3分钟(激进型)

### 7.2 可选隐蔽路径

**下水道潜入路线**:
```
起点 → 下水道井盖 → 地下通道 → 主院落下方出口 →
仓库A地板通风口 → 仓库A内部
```

**屋顶渗透路线**:
```

## 10. 视觉方向

### 10.1 整体美术风格

**推荐风格**: 暗黑工业写实主义 (Dark Industrial Realism) + 微妙色调分离

| 维度 | 定位 |
|------|------|
| 渲染风格 | 侧重光照与氛围营造的俯视角 |
