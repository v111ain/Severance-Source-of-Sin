# 玩家-NPC 交互 UX 规范

> **Status**: In Design
> **Author**: UX Designer
> **Last Updated**: 2026-04-05
> **Related Systems**: LOS & Eavesdropping System, NPC AI System
> **Implements Pillar**: 线索驱动的动态潜行 (Clue-Driven Dynamic Stealth)

---

## 1. 概述 (Overview)

本规范定义了玩家与 NPC 之间交互界面的用户体验设计，涵盖**监听/窃听机制**中关键词捕获进度的 UI 呈现。

**核心交互是"猜"**：玩家通过监听对话来逐步揭开 NPC 的真实身份。辨识不是被动避免惩罚，而是主动获取优势的策略。

**已确认的设计决策**：
- 进度条位置：头顶悬浮（随 NPC 位置）而非屏幕中央固定
- 触发半径：适中（150px）
- 分层透明度：当前锁定目标 100%，其他声源 50%

---

## 2. 玩家体验目标 (Player Fantasy)

**紧张的猎物感**：在敌暗我明的初始阶段，玩家必须对任何风吹草动保持极度敏感，躲在暗处窃听时那种"随时可能被发现的紧张"。

**侦探的解谜感**：隐藏在暗处窃听并非被动等待，而是一场实时的心理拼图。破译进度条让玩家感受到自己正在"逐步接近真相"。

**猎人反转的掌控感**：一旦完成标记，原本压抑的氛围将反转为战术上的绝对优势。标记完成的瞬间带来"破案"的成就感。

## 3. 交互流程 (Interaction Flows)

### 3.1 专注监听模式 (Focus Mode) 完整流程

```
[玩家长按监听键]
        │
        ▼
┌───────────────────────────────┐
│  进入专注模式                  │
│  - 画面边缘变暗               │
│  - 移动速度强制降至最低        │
│  - 准星锁定                    │
└───────────────────────────────┘
        │
        ▼
┌───────────────────────────────┐
│  扫描范围内的声源              │
│  - 检测半径 150px              │
│  - 按距离/方向排序             │
└───────────────────────────────┘
        │
        ▼
┌───────────────────────────────┐
│  准星对准声源                  │
│  - 当前锁定目标：高亮 (100%)   │
│  - 其他声源：半透明 (50%)      │
│  - NPC 头顶显示进度条          │
└───────────────────────────────┘
        │
        ▼
┌───────────────────────────────┐
│  持续对准积累进度              │
│  - AimAccuracy 影响积累速度    │
│  - 低于 0.5 精准度则不积累     │
└───────────────────────────────┘
        │
        ▼
┌───────────────────────────────┐
│  破译完成                     │
│  - NPC 头顶标记翻转           │
│  - 标签从"?"变为身份色        │
│  - 理智值反馈                 │
└───────────────────────────────┘
```

### 3.2 声源优先级判定流程

```
[多个声源同时存在]
        │
        ├─── 准星中心最近 ────► [锁定为当前目标] (100% 透明度)
        │
        ├─── 准星边缘 ───────► [次级目标] (50% 透明度)
        │
        └─── 超出半径 ───────► [不显示进度条]
```

## 5. 输入规范 (Input Specification)

### 5.1 专注模式控制

| 输入 | 按键 (手柄) | 按键 (键鼠) | 动作 |
|------|------------|------------|------|
| 进入/保持 | `L2` (长按) | `C` (长按) | 进入专注模式，移动速度降至最低 |
| 退出 | 松开 `L2` | 松开 `C` | 退出专注模式 |
| 微调准星 | 右摇杆 | 鼠标移动 | 调整准星位置 |
| 确认锁定 | 无（自动） | 无（自动） | 准星对准声源后自动锁定 |

### 5.2 专注模式下的移动限制

| 状态 | 移动速度 | 潜行可用 | 冲刺可用 |
|------|---------|---------|---------|
| 普通模式 | 100% | 是 | 是 |
| 专注模式 | 25% (固定) | 不可 | 不可 |

### 5.3 输入缓冲与容差

| 参数 | 值 | 说明 |
|------|-----|------|
| `MinAimAccuracy` | 0.5 | 准星精准度低于此值，进度不积累 |
| `InputBuffer` | 100ms | 退出专注模式后，重新进入的缓冲时间 |
| `AimDeadzone` | 15px | 准星中心判定死区 |

### 5.4 辅助功能设置

| 设置项 | 选项 | 默认值 |
|--------|------|--------|
| 准星大小 | 大/中/小 | 中 |
| 进度条位置 | 头顶/屏幕中央 | 头顶 |
| 透明度级别 | 100%/75%/50% | 50% (非当前目标) |

## 6. 无障碍需求 (Accessibility Requirements)

### 6.1 核心无障碍检查清单

- [ ] **键盘可用**：所有交互可通过键盘完成
- [ ] **手柄可用**：所有交互可通过手柄完成
- [ ] **最小字号**：进度条百分比文字不低于 12sp
- [ ] **颜色独立**：进度状态不依赖颜色区分（使用图案/纹理辅助）
- [ ] **无闪烁内容**：进度条填充无闪烁效果
- [ ] **字幕可用**：NPC 对话全程字幕显示
- [ ] **UI 缩放**：支持 100%-200% UI 缩放

### 6.2 色盲友好设计

| 进度状态 | 颜色表示 | 图案/纹理辅助 |
|---------|---------|-------------|
| 未开始 | 灰色 | 点状纹理 |
| 进行中 (<50%) | 黄色 | 斜条纹纹理 |
| 进行中 (>50%) | 橙色 | 粗斜条纹纹理 |
| 完成 | 绿色 + 高亮 | 实心填充 + 脉冲动画 |

### 6.3 屏幕阅读器支持

| 元素 | 读屏内容 |
|------|---------|
| 进度条 | "[NPC名称]，关键词捕获进度，[百分比]百分之[数值]" |
| 标签翻转 | "[NPC名称] 已标记为 [身份]" |
| 声源锁定 | "已锁定 [NPC名称]，请保持准星对准" |

### 6.4 认知友好设计

| 需求 | 解决方案 |
|------|---------|
| 短时记忆 | 显示已捕获关键词预览（模糊字） |
| 注意力分散 | 非目标进度条使用低对比度 (50%) |
| 操作延迟 | 进度累积有 200ms 防抖延迟 |

## 7. 视觉与音频反馈 (Visual & Audio Feedback)

### 7.1 进度条视觉反馈

| 状态 | 视觉效果 |
|------|---------|
| 0% | 空进度条，底框可见 |
| 1-49% | 黄色填充，缓慢脉动 |
| 50-99% | 橙色填充，中速脉动 |
| 100% | 绿色填充 + 闪光 + 标签翻转动画 |

### 7.2 音频反馈

| 状态 | 音效 |
|------|------|
| 进入专注模式 | 低沉氛围音 + 心跳声 |
| 锁定声源 | "滴"一声确认音 |
| 进度累积 | 微弱电流声（随进度加快） |
| 达到 50% | "咔"一声进度提示 |
| 破译完成 | 成功提示音 + NPC 标签翻转音效 |
| 退出专注 | 环境音淡入 |

### 7.3 触觉反馈 (手柄)

| 状态 | 震动模式 |
|------|---------|
| 锁定声源 | 短促低频脉冲 (50ms) |
| 进度累积 | 连续微振动（强度随进度增加） |
| 达到 50% | 中等强度单次震动 |
| 破译完成 | 强烈短促震动 (100ms) |
| 目标脱离 | 连续低频震动警告 |

## 9. 边缘情况处理 (Edge Cases)

### 9.1 多个声源重叠

| 情况 | 处理方式 |
|------|---------|
| 准星中心同时覆盖多个声源 | 优先显示距离最近的 NPC 进度条 |
| 准星覆盖范围有重叠 NPC | 显示处于 `FREE` 状态的 NPC |

### 9.2 声源超出/进入触发半径

| 情况 | 处理方式 |
|------|---------|
| 目标移出 150px 半径 | 进度条淡出消失（0.3s），已积累进度保留 |
| 新声源进入半径 | 检测到后 0.1s 内显示进度条 |

### 9.3 玩家移动导致的锁定丢失

| 情况 | 处理方式 |
|------|---------|
| 玩家移动导致准星偏离 | 进度暂停积累，精准度低于阈值时开始衰减 |
| 衰减速度 | 50%/秒（比积累慢，防止频繁丢失） |

### 9.4 专注模式中断

| 情况 | 处理方式 |
|------|---------|
| 玩家松开监听键 | 立即退出专注模式，进度保留 |
| 玩家受到攻击 | 立即退出专注模式，进度保留 |
| 玩家死亡 | 进度全部重置 |

### 9.5 目标 NPC 状态变化

| 情况 | 处理方式 |
|------|---------|
| 目标 NPC 进入 COMBAT | 锁定解除，进度保留但暂停积累 |
| 目标 NPC 死亡 | 立即移除进度条，切换到最近的声源 |

| 指标 | 预算 | 说明 |
|------|------|------|
| 单帧进度条更新耗时 | < 0.5ms | 10 个 NPC 同时显示 |
| 动画系统开销 | < 2ms | 进度条脉动、翻转动画 |
| 内存占用 (UI) | < 5MB | 进度条纹理、字体 |
