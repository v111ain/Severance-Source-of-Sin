# 玩家-NPC 交互系统视觉规范

> **Status**: Approved
> **Author**: art-director + ux-designer + game-designer
> **Last Updated**: 2026-04-05
> **Review**: 产品决策已确认

---

## 设计方向

**视觉风格**：漫画/风格化 — 线条分明，高对比度。参考《Fortnite》《Borderlands》

**核心视觉原则**：
1. 高对比度描边：所有 UI 元素采用 2px 黑色外描边
2. 饱和色彩：高饱和度色彩传达状态
3. 简洁形状：基础几何形状为主，辨识度高
4. 动态层次：通过透明度区分主次目标

## 图标设计规范

| 图标类型 | 形状特征 | 主色 | 尺寸规格 |
|---------|---------|------|---------|
| **处决** | 匕首轮廓 | `#E63946` + 银白刃部 | 32x32px, 24x24px |

- 次级目标：50% 不透明 + 静止（无脉动）

## 动画规范

### 脉动动画（已确认：固定频率）
- 周期：1.0s（不随紧张程度变化）
- 亮度变化：±10%
- 缩放变化：±3%
- 缓动：ease-in-out

### 头顶图标动画

| 状态 | 动画类型 | 参数 | 时长 |
|------|---------|------|------|
| 出现 | 缩放弹入 | 0.0→1.2→1.0 | 200ms |
| 消失 | 淡出 + 缩小 | opacity 1→0, scale 1.0→0.8 | 150ms |
| 当前目标脉动 | 微弱呼吸 | scale 1.0→1.05→1.0 | 1.0s 循环 |

### 进度条动画（已确认：纹理平铺）

| 阶段 | 进度范围 | 颜色 | 动画效果 |
|------|---------|------|---------|
| 空闲 | 0% | 灰色底框 | 无 |
| 累积中 | 1-49% | `#F1C40F` 黄色 | 脉动 |
| 累积中 | 50-99% | `#F39C12` 橙色 | 脉动 |
| 完成 | 100% | `#2ECC71` 绿色 | 闪光脉冲 + 标签翻转 |

**纹理规格**：32px 平铺纹理，配合斜条纹纹理（色盲友好）

### 径向菜单动画

| 阶段 | 动画描述 | 时长 | 缓动 |
|------|---------|------|------|
| 展开 | 子选项从中心向外弹出，依次延迟 30ms | 250ms | ease-out back |
| 选中高亮 | 选中项放大 1.15x + 外发光 | 即时 | — |
| 退出 | 快速收回至中心 | 150ms | ease-in |

**半径**：150px

### 方向指示器动画

| 状态 | 动画类型 | 参数 |
|------|---------|------|
| 空闲 | 缓慢呼吸 | opacity 0.6→0.8, 1s 周期 |
| 切换目标 | 弹跳 + 方向变换 | 200ms |

## 组件层级

```
z-index 高层
├── 径向菜单（活动时覆盖一切）
├── 屏幕提示 / 系统消息
└── 准星 / 交互反馈

z-index 中层
├── NPC 头顶图标（跟随 NPC 头顶）
├── 进度条（跟随图标下方）
└── 方向指示器（屏幕边缘）

z-index 底层
├── 画面暗角效果（专注模式）
└── 游戏画面
```

## 无障碍规范

- 所有颜色配合纹理/图案使用（不依赖纯颜色）
- 对比度满足 WCAG 2.1 AA 标准
- 支持色盲模式（纹理图案辅助辨识）
- 支持触觉反馈（手柄震动）

---

## 已确认的设计决策

| 决策项 | 确认值 |
|--------|--------|
| 脉动频率 | 固定 1.0s 周期 |
| 描边风格 | 2px 黑色外描边 + 1px 状态色内描边 |
| 进度条填充 | 32px 纹理平铺 + 斜纹 |
| 图标动画 | 无动态效果（静态图标） |
