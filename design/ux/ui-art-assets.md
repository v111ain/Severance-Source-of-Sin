## 1. 图标设计规范

### 1.1 设计原则

**图标风格**：扁平化 + 线条勾勒（方案 A）

```
设计原则：
┌─────────────────────────────────────────────────────────────────┐
│                                                                  │
│  1. 简洁硬朗          2. 无填充           3. 线条一致             │
│     ╔══════╗             ○                   ┌──┐                 │
│     ║      ║           ╱ ╲                  │  │                │
│     ║      ║          ╱   ╲                 │  │                │
│     ╚══════╝         ●─────●                └──┘                 │
│                                                                  │
│  4. 视觉平衡          5. 识别度高          6. 统一圆角           │
│       ┌──┐               ▲                   ╭────╮             │
│       │●●│              ╱ ╲                 │      │            │
│       │──│             ╱   ╲                │      │            │
│       └──┘              ▼                   ╰────╯             │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

**线条规格**：
- 线条粗细：2px（标准）、1.5px（细小元素）、2.5px（强调）
- 线条颜色：#ECF0F1（可染色）
- 线条端点： butt cap（直角）
- 线条转角：miter join（硬朗）
- 圆角半径：2px（微小弧度，保持硬朗感）

### 7.1 图标渲染规范

```
渲染规格：
┌─────────────────────────────────────────────────────────────────┐
│                                                                  │
│  PNG @2x（主要格式）：                                           │
│  - 基础尺寸：24x24px                                            │
│  - 输出尺寸：48x48px（物理像素）                                 │
│  - 用途：游戏内实时渲染                                          │
│  - 格式：PNG-24（带透明通道）                                   │
│  - 颜色配置：sRGB                                                │
│                                                                  │
│  SVG Fallback：                                                 │
│  - 逻辑尺寸：24x24px                                             │
│  - 用途：UI 编辑器预览、图标替换                                  │
│  - 兼容性：提供 SVG 版本以便程序化修改                            │
│                                                                  │
│  图标染色规范：                                                 │
│  - 使用 Unity 的 Image component 的 color 属性进行染色          │
│  - 基础颜色：#ECF0F1                                            │
│  - 运行时通过染色实现不同状态（体力低/满/中）                     │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```
