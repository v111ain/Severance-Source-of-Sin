### 1.2 色彩心理学应用

#### 主色调定义

| 色调类型 | Hex 值 | 应用场景 | 情感传达 |
|---------|--------|---------|---------|
| 深夜黑 | #0D0D0D | 主背景、遮罩层 | 压抑、未知、危险 |
| 烟灰蓝 | #1A1F2E | 次级背景、HUD 底色 | 冷静、专业、隐蔽 |
| 钢铁灰 | #3D4654 | 边框、次要元素 | 金属质感、坚硬 |
| 霓虹红 | #E63946 | 敌人标记、危险警告 | 威胁、警醒 |
| 霓虹黄 | #F4A261 | 警告提示、帮凶标记 | 注意、警示 |
| 霓虹绿 | #2ECC71 | 安全标记、无辜者 | 平静、确认 |
| 霓虹蓝 | #3498DB | 交互提示、专注模式 | 聚焦、冷静 |
| 审讯白 | #ECF0F1 | 主要文字、重要信息 | 清晰、干净 |

#### 犯罪/黑暗主题下的具体表现

```
色彩应用示例：

1. 场景色调（游戏内）
   - 废弃仓库：深蓝灰 + 暗黄灯光
   - 夜总会：深紫 + 霓虹粉/蓝
   - 码头：深青 + 橙色警示灯

2. UI 色调（界面层）
   - 正常状态：#ECF0F1 文字 on #1A1F2E 背景
   - 警告状态：#F4A261 文字 + 边框闪烁
   - 危险状态：#E63946 文字 + 脉冲效果
   - 专注状态：#3498DB 准星 + #0D0D0D 暗角

3. 心理状态映射
   - 理智稳定：饱和度正常，边缘清晰
   - 理智低下：饱和度降低 -30%，边缘模糊，噪点增加
   - 愤怒状态：红色色调偏移 +10%，屏幕轻微抖动
```

### 1.3 材质语言

#### HUD 材质规范

**扁平化微透明材质**：
```
材质属性：
- 背景透明度：70% ~ 85%
- 背景颜色：#1A1F2E（根据亮度叠加）
- 边框：无边框或 1px #3D4654
- 圆角：8px（HUD元素）、12px（面板）
- 阴影：无（扁平化风格）

实现示例：
Background Color = #1A1F2E @ 80% opacity
文字颜色 = #ECF0F1 @ 100%
图标颜色 = #ECF0F1 @ 90%
```

#### 菜单玻璃态材质

**半透明玻璃材质**：
```
材质属性：
- 背景：渐变透明（从中心向边缘衰减）
- 主色：#0D0D0D @ 60% ~ 70%
- 模糊：背景模糊（如果性能允许）或噪点叠加
- 边框：1px 半透明白 #FFFFFF @ 15%
- 内发光：边缘 #3498DB @ 10%
- 圆角：16px

玻璃效果配方：
1. 高斯模糊（模糊半径 8px）
2. 噪点叠加（噪点密度 5%）
3. 边缘发光（颜色 #3498DB，强度 10%）
4. 边框描边（1px，白色 @ 15%）
```

### 1.4 光影方向

**HUD 光影原则**：
- HUD 本身不产生投影（避免干扰游戏画面）
- 文字和图标使用轻微内阴影增加可读性
- 聚焦状态使用外发光表示激活

**光影参数**：
```
正常状态：
- 内阴影：0px 0px 2px #000000 @ 30%
- 无外发光

聚焦/激活状态：
- 外发光：#3498DB @ 20%，扩散 4px
- 边框高亮：#3498DB @ 40%

危险状态：
- 外发光：#E63946 @ 30%，扩散 6px
- 脉冲动画：强度在 20%~40% 之间循环
```

## 2. 字体规范

### 2.1 字体选择决策

**选定方案**：方案B - 思源黑体（Source Han Sans / Noto Sans CJK）+ Inter

**决策理由**：
| 考量因素 | 方案 A（圆润字体） | 方案 B（思源黑体 + Inter） |
|---------|------------------|--------------------------|
| 中文显示 | 视系统而定 | 完美支持中日韩文字 |
| 英文现代感 | 一般 | Inter 提供优秀的英文显示 |
| 数字清晰度 | 一般 | Inter 的 tabular figures 更清晰 |
| 文件体积 | 较小 | 略大但可接受 |
| 版权风险 | 需确认 | 开源免费 |

### 2.2 字体规格定义

#### 字体文件需求

```
字体家族：Noto Sans CJK SC（简体中文）
字体家族：Inter

文件列表：
├── fonts/
│   ├── NotoSansCJKsc-Regular.otf     # 常规体 ~6MB
│   ├── NotoSansCJKsc-Medium.otf       # 中黑体 ~6MB
│   ├── NotoSansCJKsc-Bold.otf         # 粗体 ~6MB
│   ├── Inter-Regular.ttf              # 常规体 ~100KB
│   ├── Inter-Medium.ttf               # 中黑体 ~100KB
│   └── Inter-Bold.ttf                 # 粗体 ~100KB
```

**备选方案**（如果文件体积是问题）：
- 仅包含 Noto Sans CJK SC 的 Regular 和 Bold
- 使用系统预装字体作为 fallback

#### 字体回退链

```
中文字体回退：
"Noto Sans CJK SC" → "Source Han Sans SC" → "Microsoft YaHei" → "PingFang SC" → "SimHei" → sans-serif

英文字体回退：
"Inter" → "Helvetica Neue" → "Helvetica" → "Arial" → sans-serif

数字字体回退：
"Inter" → "Roboto Mono" → "Consolas" → monospace
```

│ H2      │ 24px / 1.5em│ 32px  │ Bold   │ 面板标题          │

- 中文：0px

- 中文：1.5em ~ 1.8em（保证可读性）
